# repo

## Installation

1. Clone the repo.
2. Run the following command:

```
cargo install --path .
```

## Configuration

Open `repo` by running:

```
repo
```

Press `esc` to open settings page. Navigate through the settings using `up/down` arrow keys. Once finished, press `esc` to save.

### Settings

| Name | Description |
| - | - |
| `Repos path` | Path to the folder containing your repositories. |
| `Editor` | Path to the executable of your editor. |
